Aggregate mode now keeps shown thinking in one folded `● Thinking` block per Run segment, below the Run and above the answer (or above the answer when there is no Run). Its static dot is yellow while thinking, green when done and muted when interrupted. Click the title to read the parts in time order with the calls each one led to; `Ctrl+O` and expanded Runs never include thinking, steers split blocks like Runs, and hiding thinking in Pi hides the block.
