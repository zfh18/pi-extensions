Aggregate mode now keeps shown thinking in one folded `● Thinking` block per Run segment, below the Run and above the answer (or above the answer when there is no Run). Its static dot is yellow while thinking, green when done and muted when interrupted. Click the title to list its parts in time order, each folded on its own with the calls it led to (a single part opens straight to its text); `Ctrl+O` and expanded Runs never include thinking, steers split blocks like Runs, and hiding thinking in Pi hides the block.
